# CG_Project

## Build

### Visual Studio

- Open Visual Studio 2022 or 2026
- Click `Open a folder`
- Select the `CG_Project` folder
- Wait for CMake for finish configuring (~1min)
- Launch app.exe at the top

### Command Line

- Configure cmake with `cmake --preset=default`
- Build the project with `cmake --build build`
- Run the app with `.\build\Debug\app.exe`
